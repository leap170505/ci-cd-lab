
# CI/CD Lab

A Node.js web application built with Express 5 and tested using
Mocha, Chai, and Supertest.

## Requirements

- Node.js 24 or later
- Yarn 4

## Install

```bash
yarn install
```

## Run the application

```bash
yarn start
```

Open <http://localhost:3000/>

## Quality checks

```bash
yarn lint
yarn test
yarn coverage
```
